USR (Universal Semantic Representation) – reading guide

A USR describes one Hindi sentence. Each row is one concept:
  concept  index  semantic-category  gnp  head:relation  discourse  speaker-view  scope  construction

1. concept – Hindi root in WX transliteration with a sense number (xarSana_23 = "visit/sight").
   A verb carries its tense-aspect-mood after a hyphen: mila_22-wA_hE_1 (simple present), kara_1-yA_WA_1 (past perfect),
   jA_1-gA_1 (future), 0_sakawA_hE_1 (can), nA_hE_1 (has to), yA_jAwA_hE_1 (passive present).
   Words with no sense number are names (transliterate them).  $speaker = I/we, $addressee = you,
   $wyax = this/that/it (proximal = this, distal = that), $yax = relative who/which, $kim = question word.
   @ words are abbreviations written in capitals (@o.Ara.esa = ORS).
2. semantic category – place, per (person), male, female, numex (number), clocktime ...
3. gnp – pl = plural; supl = superlative; compr = comparative; kqw = verbal noun.
4. head:relation – the head index and the Paninian relation:
   k1 doer / subject, k2 object, k3 instrument (with/by), k4 recipient (to), k5 source (from), k7 location (in/on),
   k7p place, k7t time, r6 possession (A kA B = B of A), mod modifier, card number, ord ordinal, quant quantifier,
   dem demonstrative, intf intensifier, neg negation, rh cause (because of), rt purpose (for),
   krvn manner adverb, k1s / k2s predicate complement, rsm "like", rpk kar-participle (having V-ed),
   rvks / rbks participles modifying a noun (V-ing / V-ed), rasneg without, main = main verb.
5. discourse – link to another USR: samuccaya and, viroXI but, kAryakAraNa because, pariNAma therefore,
   AvaSyakawApariNAma if-then, samAnakAla when, vAkyakarma that-clause, anyawra or, uxxeSya so that.
6. speaker view / scope – markers such as hI (only), BI (also), respect, def, [shade:jA_1] (completive aspect).
7. construction – members of a multi-word unit and their role:
   [cp] complex predicate: kriyAmUla (noun/adjective) + verbalizer (light verb kara/ho) = one verb (prayoga+kara = use);
   [ne] named entity (begin/inside); [nc] noun compound; [conj] and-list (op1, op2 ...); [disjunct] or-list; [span] from-to.
8. last line – sentence type: %affirmative, %negative, %interrogative, %imperative, %pass_affirmative (passive) ...
